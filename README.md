# 🚀 Марсианский транзит (Martian Transit Odyssey)

Научно-фантастический хардкорный космический симулятор пилотируемой экспедиции на Марс.
Синтез технологий **SpaceX Starship** (дозаправка на орбите, метан/кислород, аэроторможение Belly-Flop, сальто Flip-and-Burn) и **Роскосмоса** (замкнутое жизнеобеспечение БИОС-3, стыковка «Курс», радиационный водный щит).

---

## 📁 Структура проекта

```
mars_mission/
├── GDD.md                  # Полный дизайн-документ игры со всеми формулами
├── TRACKER.md              # Дорожная карта на 8 недель (4 спринта)
├── package.json            # Манифест проекта
├── index.html              # Главная точка входа игры
├── videos/                 # Папка для AI-сгенерированных синематик-роликов
│   └── README.md           # Инструкция по добавлению видеовставок
├── locales/                # Двуязычная локализация (i18n)
│   ├── ru.json             # Русская версия
│   └── en.json             # Английская версия
├── libs/                   # Автономные библиотеки Three.js
└── textures/               # Официальные 2K текстуры NASA
```

---

## 🎮 Возможности и архитектура
* **Web-First:** работает в любом браузере, идеально адаптирован под требования Яндекс Игр.
* **Видеовставки (AI Video Cutscenes):** поддержка видео высокого разрешения (старт, стыковка, посадка, аварийные исходы).
* **Двуязычность:** мгновенное переключение RU / EN на лету.
* **Портируемость:** готов к сборке в нативное приложение для iPhone/iPad через Xcode и Capacitor.
